# imagi experience map

Browser inspection on 10 October 2026 used the public entry page and the user’s signed-in educator session. No account, classroom or project was created in imagi.

| Screen | Observed experience |
| --- | --- |
| Public entry | Prompt composer, Create CTA, classroom prompt examples, teacher/student project galleries |
| Login | Educator/student choice; educator email/password and SSO |
| Dashboard | Getting-started checklist; Lovable and Python tools; product news |
| Projects | Lovable/Python tabs, date sorting, New card; prompt ideas/examples disabled for this account |
| New project | Python or Lovable choice; Lovable disabled with district upgrade message |
| Curriculum | Course cards with grade, level, lesson count, duration and View course |
| Course | Description, lesson list, Assign to classrooms; some lessons upgrade-gated |
| New classroom | Classroom name, one alias per line; unique aliases used as student logins |
| Safety Monitor | Empty prompt feed; product says prompts are timestamped with classroom and automatically screened |

## Visual system

100px cyan left rail; pink active navigation tile; charcoal page; lighter gray cards; white headings; muted body text; cyan CTAs and links; pixel-style uppercase button lettering; generous spacing and rounded corners. Desktop course cards use two columns.

## Unverified paths

The signed-in account had no classrooms/projects and no Lovable entitlement. Student login, classroom detail, AI editor, populated safety feed, moderation execution, credit charging and publishing were not exercised. Dreamforge’s corresponding flows are proposed scaffold behavior.
